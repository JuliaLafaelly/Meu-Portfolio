## 💻 Sobre o projeto

Este é meu portfólio pessoal, desenvolvido para apresentar meus projetos, minhas competências técnicas e minha trajetória na área de tecnologia.

O objetivo é reunir meus trabalhos em um único lugar, compartilhar minha evolução como desenvolvedora e demonstrar, na prática, os conhecimentos que venho construindo por meio dos estudos e projetos.

O portfólio está em constante evolução, acompanhando meu aprendizado e meus novos desafios.

## 🎯 Objetivos

- Apresentar meus projetos e experiências práticas.
- Demonstrar minhas habilidades em desenvolvimento web.
- Compartilhar minha evolução e meus aprendizados.
- Facilitar o acesso ao meu código e aos meus trabalhos.
- Construir minha presença profissional na área de tecnologia.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação e organização do conteúdo |
| CSS3 | Estilização, layout e responsividade |
| JavaScript | Interatividade e funcionalidades da interface |
| Git | Controle de versão do projeto |
| GitHub | Hospedagem do código e acompanhamento das alterações |

## ✨ Funcionalidades

- **Apresentação pessoal:** informações sobre minha trajetória e meus objetivos.
- **Competências técnicas:** tecnologias e ferramentas que estudo e utilizo.
- **Projetos:** apresentação dos meus trabalhos com descrições e links para os repositórios.
- **Navegação intuitiva:** organização das seções para facilitar a experiência do visitante.
- **Design responsivo:** proposta de interface adaptável a diferentes tamanhos de tela.
- **Contato:** espaço para facilitar conexões e oportunidades profissionais.
